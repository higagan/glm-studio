# Medibrick Competitor Analysis

## 🏆 Primary Competitor: Jobizo.com

### What They Do Well
- 10M+ shifts fulfilled
- 150+ hospitals, 60K+ professionals
- Mobile app for professionals
- AI matching
- Permanent + locum jobs

### Gaps We Can Exploit
| Gap | Our Advantage |
|-----|--------------|
| Job-seeker focused | **Institution-first** — hospitals post, pros apply |
| No Ayurvedic coverage | **Full AYUSH support** (Ayurvedic, Unani, Siddha) |
| Primarily allopathic doctors | **Nurses, technicians, therapists** |
| Hospital-centric | **Clinics, diagnostic centers, wellness centers** |
| No bilateral reviews | **Both parties review each other** |

## 📊 Market Positioning

### Jobizo = LinkedIn for healthcare jobs
### Medibrick = Uber for healthcare shifts

| Aspect | Jobizo | Medibrick |
|--------|--------|-----------|
| User initiates | Professional searches | Hospital posts need |
| Job type | Permanent + temp | Temp/locum only |
| Coverage | Allopathic doctors | Allopathic + AYUSH + nurses + techs |
| Review system | One-way? | Bilateral trust building |
| Institutions | Hospitals | Hospitals + clinics + diagnostic + wellness |
| Speed | Variable | 48-hour guarantee (target) |

## 🎤 Pitch Differentiation

**To Hospitals:**
> "Jobizo makes you compete for doctors. Medibrick brings verified professionals to your empty shifts in 48 hours — including Ayurvedic practitioners and nurses, not just allopathic doctors."

**To Professionals:**
> "Jobizo is for full-time jobs. Medibrick is for flexible shifts — pick up a 2-day ICU nursing shift or a weekend Ayurvedic consultation. Work when you want."
