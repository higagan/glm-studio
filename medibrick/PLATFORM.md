# Medibrick / MedicoreJobs — Platform Overview

## 🎯 Purpose
Digital platform connecting healthcare providers (hospitals, clinics, diagnostic centers, wellness centers) with healthcare professionals (doctors, Ayurvedic practitioners, nurses, technicians) for **temporary shifts and locum jobs**.

## 👥 User Roles

### Healthcare Facilities
- Create institution profile with verification
- Post locum shifts (department, dates, duration, requirements)
- Browse and select applicants
- Review professionals after shift completion

### Healthcare Professionals  
- Create profile with qualifications, specialties, license uploads
- Browse locum shifts by department/date/location
- Apply with personalized messages
- Receive notifications on application status
- Review hospitals after shift completion

## 🔑 Key Differentiators vs Jobizo

| Feature | Medibrick | Jobizo |
|---------|-----------|--------|
| **Focus** | Temporary/locum shifts | Permanent + locum |
| **Professional types** | Allopathic + Ayurvedic + Nurses + Techs | Primarily allopathic |
| **Shift duration** | Single day to few weeks | Any duration |
| **Verification** | License/certification upload | Profile-based |
| **Reviews** | Bilateral (hospital ↔ professional) | Unclear |
| **Departments** | All departments + wellness | Hospital-focused |
| **Institution types** | Hospitals, clinics, diagnostic, wellness | Hospitals mainly |

## 🚀 Core Features

1. **Registration & Verification**
   - Institutions: License verification, facility details
   - Professionals: Qualification docs, license upload, skills

2. **Shift Posting**
   - Department, role, dates, duration, location, timing
   - Special requirements (equipment, certifications)
   - Edit/pause/delete postings

3. **Application & Matching**
   - Filter by: department, date, location, professional type
   - Apply with message/docs
   - Hospital reviews and selects

4. **Reviews & Trust**
   - Post-shift ratings both ways
   - Visible on profiles
   - Builds reputation system

5. **Notifications**
   - New shifts matching criteria
   - Application status updates
   - Messages between parties

6. **Search & Discovery**
   - Hospitals: filter pros by skills, ratings, availability
   - Pros: filter shifts by dept, date, location, institution type

7. **Dashboards**
   - Hospital: manage postings, applications, past engagements
   - Professional: profile, applied jobs, status, calendar

8. **Admin Panel**
   - User management
   - Compliance oversight
   - Dispute handling
   - Platform analytics
