# 🚨 Core Pain Point: The "Yes but No-Show" Problem

## The Hospital's Nightmare

Hospital admin confirms a nurse for tomorrow's shift.
Nurse says "Yes, I'll be there."

Morning comes. Nurse doesn't show. Doesn't pick up the phone.

Hospital is now short-staffed with 40 patients and zero backup.

## Why It Happens

| Reason | Explanation |
|--------|-------------|
| **Better offer elsewhere** | Another hospital offers more money last minute |
| **Multiple bookings** | Professional booked 2-3 places, picked the best |
| **No skin in the game** | Zero penalty for not showing up |
| **No verification** | Anyone can say yes, no credibility check |
| **Poor communication** | No real-time status updates |

## Current Workarounds (Broken)

- Hospital calls 10 people, hopes 1 shows up
- Relies on "known" agencies (expensive, limited pool)
- Keeps internal float staff (costly idle time)
- Manager works double shift (burnout)

## The Medibrick Guarantee

**For Hospitals:**
- Professional confirms → deposit locked (₹500-2000)
- Professional shows up → deposit refunded
- Professional no-shows → deposit to hospital + strike on profile
- Hospital can rate: "Showed up", "Late", "No-show"
- 3 no-shows = profile suspended

**For Professionals:**
- Confirm shift → deposit held (refundable)
- Complete shift → deposit back + payment
- Cancel >24h before → full refund
- Cancel <24h before → 50% penalty
- No-show → full deposit forfeited + strike

## Instant Backup System

If confirmed professional drops:
1. Auto-notify #2 applicant: "Shift available immediately"
2. #2 can accept in 30 minutes
3. If #2 declines, go to #3
4. Hospital always has backup

## Communication Protocol

- **T-24h:** Reminder notification
- **T-2h:** "Are you en route?" confirmation
- **T-30min:** "Mark as arrived" button
- **No response at T-1h:** Escalate to backup
