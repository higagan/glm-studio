## QuizCult — Massive Build Session (~3 hours)

### What We Built
QuizCult: A viral social quiz game where users prove they know more than friends. Users can type ANY topic → AI generates a quiz in ~90 seconds → play → challenge friends.

### Architecture
- **Frontend:** Next.js 14 + Tailwind + Framer Motion
- **Backend:** FastAPI + SQLite + SQLAlchemy async
- **AI:** Ollama (qwen2.5:7b) for quiz generation + AI roasts
- **Share:** Server-side Pillow PNG cards + WhatsApp share

### Session Progression

#### Phase 1: Fix Everything (2+ hours)
- Started with broken React frontend ("Loading challenges" stuck)
- Fixed hydration mismatch by making page.tsx server-rendered with `getChallenges()`
- Fixed QuizPlayer — all answers showed as correct (hardcoded `index === 0`)
- Fixed answer feedback — added `isCorrect`, `correctIndex` state
- Fixed backend `avg_score` schema (int vs float mismatch causing serialization errors)
- Fixed `ScoreComparison` endpoint (was passing ORM model, schema expected Pydantic)
- Restarted both services ~10 times during debugging

#### Phase 2: Friend Share Flow (30 min)
- Tested end-to-end: play quiz → get share token → friend opens challenge link
- Fixed challenge link to show actual challenge_id (was null)
- Added head-to-head comparison screen ("You beat them by 2 points!")
- Verified WhatsApp share text includes topic name

#### Phase 3: The PM Pivot (30 min) — **Biggest Insight**
- User asked: "Not just trending, could be anything right? Think like PM"
- Realized the real product isn't "trending news quizzes" — it's "turn ANY topic into a challenge"
- Built `POST /api/quizzes/create` — user types any text → AI generates quiz
- Tested: typed "Virat Kohli" → generated 10 questions in 90 seconds
- Verified: score 10/10 → share link created → AI roast generated

### Key Bugs Found & Fixed
1. **avg_score int/float** — Pydantic validation failed on ORM float → schema int
2. **correct_answer missing** — Gameplay start API omitted it for "security" but UI needed it
3. **ScoreComparison serialization** — Passing ORM model where Pydantic model expected
4. **Challenge link broken** — `challenge_id` was null in `ChallengeLinkInfo` response
5. **Hydration failure** — Client-side fetch failing silently, switched to SSR + client

### PM Insights Learned
- **The real viral loop:** Personal topic → User creates → Plays first → Challenges friend → Friend sees YOUR score → Plays to beat you
- **Topics matter more than features:** A quiz about "Virat Kohli" beats "Python Mastery" for a cricket fan every time
- **"Anonymous" kills virality:** Need user names for emotional hook
- **Infinite > Curated:** User-generated topics (any text) >> pre-made quizzes (7 topics)
